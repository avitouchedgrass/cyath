## Overview & Clinical Problem

Over **73% of young adults and knowledge workers** suffer from chronic circadian desynchronization (*Social Jetlag*) driven by erratic sleep windows, late-night screen exposure, and high-glycemic nocturnal eating. 

Conventional healthcare operates reactively: metabolic syndrome, pre-diabetes, and chronic fatigue are typically detected only after irreversible tissue insulin resistance or elevated HbA1c blood thresholds are breached years later.

**Cyath** bridges this diagnostic void by deploying multimodal generative AI and biostatistics to identify subclinical metabolic and circadian drift from everyday behavioral telemetry before clinical pathology manifests.

## Core Systems & Clinical Architecture

### 1. Multimodal Chrononutrition AI (Gemini 3.1 Flash)
Natural language and camera photo scans are evaluated by a clinical Gemini pipeline that models nutrient bioavailability and meal timing against peripheral circadian clocks:
- **`glycemicRisk`** — Classifies meals (*Low, Moderate, Spike Risk*) based on glycemic index and fiber/protein buffering.
- **`circadianImpact`** — Contextual physiological breakdown mapping macronutrients to circadian insulin sensitivity, mTOR activation, and postprandial adenosine clearance.
- **`allostaticScore`** — 1–5 systemic metabolic load index.
- **Deterministic Heuristic Fallbacks** — Ensures 100% offline meal analysis uptime even without an active API key or connection.

### 2. Chrono-Metabolic Biostatistics Engine (Pearson r² Matrix)
Client-side statistical engine correlating circadian biomarkers against subjective energy and cognitive output:
- **Postprandial Amino-Acid Floor** vs. **Vitality Index**
- **Circadian Phase Consistency** (sleep/wake timing variance) vs. **Peak Cognitive Output**
- **Adenosine Clearance Window** (caffeine cutoff timing) vs. **Deep Sleep Duration**
- **Morning Photonic Lux Latency** (sunlight within wake window) vs. **Cortisol Awakening Response Proxy**
- **Interactive Scatter Nodes & 24h Predictive Curve** — Drag biomarker coordinates in real time to simulate how adjusting circadian inputs influences metabolic vitality.

### 3. Adaptive Allostatic Pacing (Burnout & Chronic Fatigue Management)
For individuals presenting with chronic fatigue, ME/CFS, Long COVID, or burnout symptoms, Cyath eliminates punitive streak anxiety:
- Biometric triggers: sleep duration < 5.5h, morning rested rating ≤ 2/10, or energy collapse.
- Automatically activates a **15-minute essential habit floor** (*"Recovery Sprint"*).
- Applies **Kintsugi-philosophy forged streaks** — preserving long-term momentum through recovery periods without guilt.

### 4. Monumental 16-Bit Living Sanctuary Island
A floating island diorama that reacts to biological rhythm and habit consistency:
- **10 Evolutionary Tiers** across 3 distinct master suites:
  - *The Pillow Fighter* (Circadian restoration, blue-light defense, 8h slow-wave sleep)
  - *The Iron Forge* (Protein floor adherence, resistance training, anabolic recovery)
  - *Deep Worker* (Single-tab monotasking, digital hygiene, high-focus sprints)
- **Wind-Drift Pixel Clouds & Stepped Ground Shadows**: Pixel-rendered animations reacting to device performance and reduced motion settings.
- **Synthesized 8-Bit Audio**: Audio cues rendered on-the-fly via the Web Audio API with zero external sound asset dependencies.

### 5. Daily Debrief & Evening Brass Seal Ceremony
- Turn-by-turn daily check-in evaluating sleep architecture, sunlight latency, protein floor, and caffeine cutoff.
- Interactive **press-and-hold brass signet stamping** with celebratory particle physics and +50 XP awards.
- Automatically pins verified daily receipts to the 30-day archival log book.

### 6. Clinical Weekly Dossier & PDF Export
- Generates a 7-day retrospective computing focus hours reclaimed, afternoon slump reduction percentage, and clinical consistency grade (A+ through C).
- One-click print/downloadable vector PDF dossier with clinical demographics and Pearson correlation plots.

### 7. Specimen Reliquary (Trophies & Badges)
- 20 archival badges categorized by sanctuary ascension, check-ins, circadian biometrics, nutrition, and streaks.
- Bronze, Silver, Gold, and Celestial tiers with dynamic mastery multipliers (1x–20x) and PNG export cards.

## Getting Started

### Prerequisites
- **Node.js**: v18.18.0 or later (Node 20+ recommended)
- **Package Manager**: npm, pnpm, or yarn
- **Google Gemini API Key**: Free tier from [Google AI Studio](https://aistudio.google.com/) *(optional for demo mode, required for live AI parsing)*
- **Supabase Account**: Free tier from [supabase.com](https://supabase.com/) *(optional for guest demo mode, required for remote cloud sync)*

### 1. Clone the Repository

```bash
git clone https://github.com/avitouchedgrass/cyath.git
cd cyath
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Configure Environment Variables

Create `.env.local` in the project root:

```env
# Supabase Configuration (Optional for guest demo, required for cloud sync)
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-anon-key

# Google Gemini API (Optional for demo heuristic fallbacks, required for live AI vision)
GEMINI_API_KEY=your-gemini-api-key

# Application Canonical URL
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```

### 4. Run Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.  
To jump directly into the full guest demo, navigate to [http://localhost:3000/demo](http://localhost:3000/demo).

### 5. Run Test Suite

```bash
npx vitest run
```

### 6. Production Build

```bash
npm run build
npm run start
```
